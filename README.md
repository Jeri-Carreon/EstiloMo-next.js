# EstiloMo

EstiloMo is a barbershop appointment management system developed for The Barbs Bro. It helps manage appointments, customers, services, and other barbershop operations through a centralized web-based system.

## Live Demo

The current version of EstiloMo can be accessed at:

https://estilomo.codeegoh.com/

## Features

- Appointment management
- Customer management
- Service management
- User roles and access control
- Barbershop scheduling
- Financial metrics dashboard
- AI-assisted report generation

## Technologies

- Next.js
- Prisma
- Supabase
- PostgreSQL

## Project

Developed as a capstone project by Fantastic 4 at Far Eastern University – Diliman.
